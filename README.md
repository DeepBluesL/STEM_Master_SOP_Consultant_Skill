# STEM Master SOP Consultant Skill

An English-language skill for developing evidence-grounded STEM master's statements of purpose.

## Use

Download this repository into a folder named `masters-sop-skill` in your agent's skills directory, or provide `SKILL.md` directly with your request.

Start with [SKILL.md](SKILL.md). It supports diagnosis and comparison, outlining and revision, official program research, and literature-grounded future plans.

The skill prioritizes technical reasoning, personal contributions, coherent development, program fit, and the applicant's voice. It adapts to research, professional, and interdisciplinary master's programs.

## Examples

- Diagnose my research MS draft and suggest three substantive improvements.
- Revise this MEng project paragraph while preserving my technical facts.
- Research this program and connect its resources to my experience.
- Develop two grounded future directions from my deployment experience.

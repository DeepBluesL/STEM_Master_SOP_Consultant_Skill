# Rhetorical moves

Use labels to describe what a passage accomplishes and where the argument needs development. Multiple labels can apply to one paragraph.

| Label | Evidence to look for |
| --- | --- |
| MOTIVATION | A stated reason to pursue the work or degree |
| PROBLEM | A scientific question or practical need |
| CHALLENGE | A concrete obstacle in the applicant's setting |
| ACTION | A step the applicant or team took |
| TECHNICAL_CONTRIBUTION | An identifiable component, method, dataset, or analysis owned by the applicant |
| DECISION_RATIONALE | Why a choice addressed the constraint |
| OUTCOME | A reported result, deliverable, adoption, or publication status |
| REFLECTION | What the experience meant to the applicant |
| INTELLECTUAL_GROWTH | A change in understanding evidenced across decisions or experiences |
| RESEARCH_INTEREST | A question or topic the applicant wants to investigate |
| WHY_SCHOOL | Relevant university-wide resources or environment |
| WHY_PROGRAM | Specific curriculum, learning structure, or project opportunities |
| WHY_FACULTY | A reasoned connection to a faculty member's work |
| FUTURE_PLAN | A plausible next learning or project step |
| CAREER_GOAL | A post-degree role, field, or contribution |
| TRANSITION | The relationship that advances one passage into another |

The local corpus analysis also uses HEADER and BACKGROUND for document scaffolding and descriptive preparation. Annotations record source blocks because page breaks can divide a paragraph. Read continuation blocks together.

A useful diagnosis connects a passage to its missing inference: a method name may need a decision rationale; an outcome may need personal ownership; an ambition may need an intermediate learning step. The labels support that judgment.
